D.E.W. MORE LOGISTICS WEBSITE

Upload index.html, services.html, about.html, contact.html, style.css, script.js to the root of your GitHub repository.
GitHub repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.

IMPORTANT:
- The quote form opens the visitor’s email application and requires them to press Send. It does NOT store or automatically submit information. To receive quote forms without an email app, integrate a form service later.
- Before publishing, verify all business descriptions and confirm the services, operating authority, insurance, and availability you can actually offer. No unverified delivery counts or licensing claims are included.
- Hero photo is served from Unsplash and fonts from Google; external access is needed for these assets.
- To use the website on a GoDaddy domain, configure Custom domain under GitHub Pages and update appropriate GoDaddy DNS records according to GitHub instructions.
